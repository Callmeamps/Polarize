# grapesjs-studio-sdk-email

> Visual email template builder

## What it does

GrapesJS Studio SDK for email provides a drag-and-drop editor specifically optimized for creating responsive email templates that work across all email clients.

## Features

- **Email-Specific Components** - Pre-built blocks optimized for email
- **Responsive Templates** - Works on mobile, desktop, and all email clients
- **Style Manager** - Edit CSS properties via UI
- **Export** - Generate email-compatible HTML output
- **Templates** - Start from pre-built email templates

## Source

- GitHub: https://github.com/grapesjs/studio-sdk
- Documentation: https://app.grapesjs.com/docs-sdk/project-types/email

## Usage

To create an email template:
1. Open a project in Polarize
2. Ask the agent to use the grapesjs-studio-sdk-email skill
3. Choose a template or start blank
4. Customize blocks, style, and export

## Integration

Connect to Polarize's storage to save email templates as project files.

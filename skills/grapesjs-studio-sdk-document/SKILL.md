# grapesjs-studio-sdk-document

> Visual document builder

## What it does

GrapesJS Studio SDK for documents provides a visual editor for creating professional documents, reports, and publications.

## Features

- **Rich Text Editing** - Prosemirror-powered text editing
- **Block-Based** - Drag-and-drop document components
- **Templates** - Start from pre-built document templates
- **Style Manager** - Edit styles via UI
- **Export** - Generate HTML/PDF-ready output

## Source

- GitHub: https://github.com/grapesjs/studio-sdk
- Documentation: https://app.grapesjs.com/docs-sdk/project-types/document

## Usage

To create a document:
1. Open a project in Polarize
2. Ask the agent to use the grapesjs-studio-sdk-document skill
3. Choose a template or start blank
4. Add text, images, tables, and other blocks
5. Export when done

## Integration

Connect to Polarize's storage to save documents as project files.
